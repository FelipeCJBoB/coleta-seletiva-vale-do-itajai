# Prints das telas (Etapa 2)

12 imagens (1080×2160, emulador Pixel 5, Android 14) geradas pelo teste `CapturaDeTelasTest` com **dados de demonstração**. Servem para o relatório (5.1.1) e o vídeo.

Para gerar de novo: GitHub > Actions > CI > Run workflow (branch desejada) > baixar o artefato `prints-das-telas` da execução.

São capturas de tela renderizadas com estados de exemplo, não gravações de uso real do app.
